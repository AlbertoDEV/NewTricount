# NewTricount-integracion
Aplicación para compartir y gestionar gastos en grupo. Permite crear grupos, añadir participantes y registrar gastos. Desarrollada con HTML, CSS, JavaScript y Java.

## Datos de Ejemplo

Para facilitar la prueba y demostración de la aplicación, el sistema crea automáticamente un conjunto de datos de ejemplo la primera vez que se inicia.

### Usuario de Ejemplo

Puedes iniciar sesión con el siguiente usuario:

-   **Usuario:** `admin_user`
-   **Contraseña:** `password`

### Casos de Uso de Ejemplo

Al iniciar sesión con `admin_user`, encontrarás dos grupos preconfigurados para demostrar los diferentes roles y funcionalidades:

1.  **Viaje a la Playa**
    -   En este grupo, `admin_user` es el **administrador**.
    -   El grupo incluye a otros dos miembros (`member_user1` y `member_user2`).
    -   Se han añadido varios gastos pagados por diferentes miembros para que puedas ver cómo se calculan las deudas.

2.  **Cena Semanal**
    -   En este grupo, `admin_user` es un **miembro normal**.
    -   El administrador de este grupo es `member_user1`.
    -   También contiene gastos para ilustrar el funcionamiento desde la perspectiva de un miembro no administrador.
